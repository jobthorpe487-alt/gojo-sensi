# GOJO SENSI

GOJO SENSI is a mobile-friendly Free Fire sensitivity generator.

## Features

- Device presets
- Play-style presets
- Sensitivity sliders
- One-tap settings
- Drag settings
- Copy settings
- Mobile responsive design
- Progressive Web App support
- Offline caching
- GitHub Pages compatible
